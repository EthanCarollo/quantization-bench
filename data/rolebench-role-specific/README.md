# RoleBench role-specific subset

Ten unique English roles sampled deterministically from the `role_specific/test.jsonl` file of the pinned RoleBench revision. It uses the same ten roles as the generalization subset, while retaining the role-specific questions and first RoleGPT-generated reference answers. Source and local SHA-256 hashes are in `source.json`.

Source: [ZenMoore/RoleBench](https://huggingface.co/datasets/ZenMoore/RoleBench), Apache-2.0.
