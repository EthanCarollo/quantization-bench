# RoleBench generalization subset

Ten unique English roles sampled deterministically from the `general/test.jsonl` file of the pinned RoleBench revision. The rows retain the test questions and first RoleGPT-generated reference answers. Source and local SHA-256 hashes are in `source.json`.

Source: [ZenMoore/RoleBench](https://huggingface.co/datasets/ZenMoore/RoleBench), Apache-2.0.
