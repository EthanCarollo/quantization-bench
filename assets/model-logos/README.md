# Local model family marks

These assets identify the locally evaluated model families. They are shown for identification only; Quantization Bench is not affiliated with or endorsed by their owners.

- `google-g.png` — Gemma mark from [Google AI for Developers](https://ai.google.dev/gemma/images/gemma_sq.png).
- `qwen.png` — Qwen mark from the official [Qwen website repository](https://raw.githubusercontent.com/QwenLM/qwenlm.github.io/main/static/favicon.png).
- `mistral.png` — Mistral mark from the [Mistral brand page](https://mistral.ai/brand/) and its website asset `https://mistral.ai/images/heros/brand/logo-gray.png`.
- `liquid-icon.svg` — Liquid AI icon from its [official website](https://www.liquid.ai/), cropped from the icon portion of the site's `liquid-ai-black.svg` wordmark.
